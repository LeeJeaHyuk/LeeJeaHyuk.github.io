구글 지도 타임라인에 저장된 이동 기록을 시간순으로 재생하는 타임랩스 영상으로 만드는 방법이다. 휴대전화에서 기록을 JSON 파일로 내보낸 뒤, 해당 파일을 지원하는 도구에서 영상으로 저장한다.

[이 영상을 사용한 글: 내 삶에 AI를 어떻게 활용할까](/ai/ai-in-my-life/)

## 1. 타임라인 기록 확인하기

구글 지도 앱에서 **프로필 사진 → 내 타임라인**을 연다. 영상으로 만들 날짜에 이동 기록이 있는지 먼저 확인한다. 영상에 담을 기간의 기록이 남아 있어야 한다.

## 2. 타임라인 데이터 내보내기

아래 메뉴 경로는 2026-10-19 기준이다. 기기와 앱 버전에 따라 메뉴 이름이나 위치가 다를 수 있다.

### Android

1. 휴대전화의 **설정** 앱을 연다.
2. **위치 → 위치 서비스 → 타임라인**으로 이동한다.
3. **타임라인 데이터 내보내기 → 계속**을 선택한다.
4. 파일을 보관할 위치를 정한 뒤 **저장**한다.

저장된 JSON 파일을 영상 제작에 사용한다. 컴퓨터에서 작업하려면 내보낸 파일을 컴퓨터로 옮긴다.

### iPhone / iPad

1. 구글 지도 앱에서 **프로필 사진 → 설정**을 연다.
2. **계정 설정 → 개인 콘텐츠**로 이동한다.
3. **위치 설정 → 타임라인 데이터 내보내기**를 선택한다.
4. 공유 화면에서 **파일에 저장**을 선택한다.
5. 저장 위치를 정한 뒤 **저장**한다.

내보낸 파일은 `location-history.json`으로 저장된다. 컴퓨터에서 작업하려면 이 파일을 옮긴다.

## 3. 검색어로 영상 제작 도구 찾기

검색창에 아래 검색어 중 하나를 입력한다.

```text
구글 타임라인 JSON 타임랩스 만들기
Google Timeline JSON timelapse video
Google Maps Timeline animation export MP4
```

검색 결과에서는 **휴대전화에서 내보낸 타임라인 JSON을 읽을 수 있는지**, **결과를 영상 파일로 저장할 수 있는지**를 확인한다. 지도에 경로를 표시하는 기능과 영상으로 내보내는 기능은 구분해서 확인한다.

파일을 읽지 못한다면 해당 도구가 지원하는 타임라인 데이터 형식을 확인한다. 같은 JSON 파일이어도 내부 구조가 다를 수 있다.

## 4. 기간과 재생 속도를 정해 영상 저장하기

1. 내보낸 JSON 파일을 불러온다.
2. 영상에 담을 시작일과 종료일을 정한다.
3. 도구에서 제공하는 범위 안에서 재생 속도와 지도 확대 정도를 조절한다.
4. 짧은 구간을 미리 재생해 날짜 순서와 이동 경로를 확인한다.
5. 전체 영상을 만든 뒤 MP4 등 지원하는 영상 형식으로 저장한다.
6. 저장된 파일을 열어 영상이 정상적으로 재생되는지 확인한다.

기간 선택이나 속도 조절, 영상 저장 방식은 도구마다 다르다. 원하는 기간과 저장 형식을 지원하는지 확인한 뒤 전체 영상을 만든다.
